## 🎯 KEY CONCEPTS (Quick Reference)

### The Problem
Traditional materials discovery tests all 230 space groups → expensive!

### Our Solution
Use ML to predict top candidates → test only those → 10-100× faster!

### The Workflow
```
Composition → ML predicts → Structure generation → 
Rapid DFT → Accurate DFT → Database entry
```

## 🛠️ TECHNICAL REQUIREMENTS

### Software Needed

**Essential:**
```bash
Python 3.10+
numpy, pandas, matplotlib, seaborn
scikit-learn
pymatgen, mp-api
matminer
```

**For ML:**
```bash
pytorch OR tensorflow
wandb (experiment tracking)
```

**For DFT (if doing validations):**
```bash
VASP or Quantum Espresso
ASE (Atomic Simulation Environment)
Atomate (workflow automation)
```

### Hardware Needed

**For ML training:**
- CPU: 16-32 cores
- RAM: 64-128 GB
- GPU: Optional but helpful (RTX 4090 or A100)
- Storage: 500 GB - 1 TB

**For DFT validation:**
- HPC cluster access
- 100-1000 CPU cores
- 4-8 GB RAM per core
- 10-50 TB storage

### Data Sources

**Free databases (used for training):**
- Materials Project: https://materialsproject.org/
- JARVIS: https://jarvis.nist.gov/
- Crystallography Open Database (COD)

**Subscription databases (optional):**
- OQMD: Can bulk download
- ICSD: University subscription
- Cambridge Structural Database (CSD)
